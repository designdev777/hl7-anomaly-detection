# HL7 Anomaly Detection System - Render.com Edition

Real-time HL7 message anomaly detection dashboard, deployable for free on Render.com.

## 🚀 Live Demo
[https://hl7-anomaly-detection.onrender.com](https://hl7-anomaly-detection.onrender.com)

## ✨ Features
- Real-time monitoring dashboard
- Auto-refreshing statistics
- Anomaly detection and classification
- Patient activity tracking
- Severity-based alerting
- Responsive design
- Sample data generator for demo
